Build a production-quality full-stack web application called SheGuard — Women Safety & Empowerment Platform.

This project is for a college presentation and must look professional, modern, polished, responsive, and functional. Do NOT create a fake prototype with buttons that do nothing. Every implemented feature must work correctly, and anything that cannot safely or realistically be implemented must be clearly presented as informational rather than pretending it is functional.

IMPORTANT DEVELOPMENT RULE:
Do not rush into adding features without testing them. After implementing each major feature, test it, fix errors, and only then continue. At the end, perform a complete bug-fixing and quality-assurance pass.
